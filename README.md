## 官网写"Up to 6.0 GHz"，实际拿到的是什么 CPU

Evoxt 官网的宣传语是"最高 6.0 GHz+ 的 CPU 频率，按低频 CPU 的价格卖"。这句话是真的，但它描述的是上限，不是保证。

第三方 YABS 测试记录里，这台机器上跑过的处理器有两个型号：EPYC-Genoa（9004 系列）和 EPYC-Milan（7003 系列）。首尔节点的 VM-0.5 实测单核加速到 4291 MHz，雅加达节点实测 4192 MHz，都远低于 6.0 GHz。Geekbench 6 的单核成绩分布也说明了同样的事：VM-1 是 2390，VM-2 是 1964，VM-4（Milan）是 2572，VM-8 是 2722。同一家商家、同一套套餐，单核成绩能差出 700 多分，说明你拿到哪颗 U、跑到多少频率，取决于具体机房和宿主负载。

这不影响它比同价位的老 Xeon E5 方案快，但意味着**不要按"6.0 GHz"去做容量规划**。Geekbench 6 单核 2000 分上下、多核按核心数线性叠加，是更可靠的预期。VM-8（8 核 16GB）的多核成绩是 11459，接近 VM-1 的 5 倍，这个倍率对跑并发任务是有参考价值的。

顺带一提，同一批测试里磁盘读取在 1382 MB/s 到 2137 MB/s 之间，网络下载从 935 Mbit/s 到 9605 Mbit/s 都有记录。跨节点差异比跨套餐差异更大。

**多站点托管、跨境电商后台。** VM-2，2 核 4GB，$11.99/月。4GB 是能同时装下 Web 服务、数据库和缓存的最低门槛。1TB 流量对正常访问量的展示型站点不会成为瓶颈。

**编译、CI、多容器、爬虫。** VM-3 或 VM-6。这两档的内存和核心比是 1:1，适合把 CPU 跑满但内存吃得少的负载。VM-3 的 4 核 4GB 在 $15 这个价位不常见。

**Windows 远程桌面、需要图形界面的软件。** VM-4 起步。雅加达节点的评测确认 Evoxt 支持 Windows Server 2012/2016/2022，但 60GB 盘和 8GB 内存是跑得舒服的底线，再往下会很难受。

## 机房、流量和几条容易踩的限制

Evoxt 是马来西亚公司（Evoxt Sdn Bhd，吉隆坡），持自有 AS149440，机房覆盖北美、欧洲、亚洲、澳洲。公开评测里能确认的具体节点有香港、日本大阪、马来西亚、韩国首尔、印尼雅加达。

**同一档套餐在不同网络类型下流量不同，价格基本一样。** 这是最容易被忽略的一条。官网把香港、大阪归为 Premium 网络，马来西亚归为 Premium Plus 网络，这两类网络的月流量配额比标准网络少。也就是说，你花 $5.99 买 VM-1，选香港机房拿到的流量会少于选一个标准网络机房。价格相同、配额不同，选机房等于选流量。马来西亚 Premium 网络的最小档价格还和其他地区不一样，具体以下单页为准。

第三方统计显示 Evoxt 在售套餐共 33 个，官网价格页展示 11 个规格，差额来自同一规格在不同网络类型下的独立 SKU。挑的时候不要只看规格名，要看清楚落在哪个网络。

**线路不对中国大陆做优化。** 官网没有 CN2 GIA、9929、CMIN2 这类承诺。首尔节点走的是 Korea Telecom 直连，因为地理近，中国沿海和北方地区延迟表现不错；但移动方向可能绕道日本，晚高峰会有波动。这是地理红利，不是线路优化。指望它替代中国优化线路的人会失望。

**IP 属性按节点不同。** 雅加达节点实测是广播 IP，能解锁 ChatGPT 和 TikTok；首尔节点是原生韩国 IP。这两个结论不能推广到所有机房，买之前按自己的用途去查对应节点的实测。

**支持的系统和支付方式。** CentOS 7.9、Debian、Ubuntu、AlmaLinux、RockyLinux、Windows Server 2012/2016/2022 都在列表里。付款支持信用卡、借记卡、PayPal、Bitcoin 和 USDt Tron。
